# Purchase Planner — User Stories

## Guest User Stories

### US-01 — Register an account

As a guest, I want to create an account so that I can save and manage my shopping lists.

### US-02 — Log in

As a guest, I want to log in so that I can access my saved data.

### US-03 — View the home page

As a guest, I want to view the home page so that I can understand how Purchase Planner works.

---

## User Account Stories

### US-04 — Stay logged in

As a user, I want to remain logged in after refreshing the page so that I do not need to enter my credentials repeatedly.

### US-05 — Log out

As a user, I want to log out so that my account remains secure.

---

## Product Catalog Stories

### US-06 — Browse products

As a user, I want to browse available products so that I can find items for my shopping list.

### US-07 — Search for a product

As a user, I want to search for products by name so that I can find them quickly.

### US-08 — Filter products by category

As a user, I want to filter products by category so that I can view only relevant items.

### US-09 — View product details

As a user, I want to view product information so that I can confirm the brand, size, and category before adding it.

---

## Shopping List Stories

### US-10 — Create a shopping list

As a user, I want to create a shopping list so that I can plan my purchases.

### US-11 — Name a shopping list

As a user, I want to give my shopping list a custom name so that I can identify it later.

### US-12 — Add a product to a list

As a user, I want to add products to my shopping list so that I can include them in the price comparison.

### US-13 — Change product quantity

As a user, I want to change product quantities so that the calculated total matches what I need to buy.

### US-14 — Remove a product from a list

As a user, I want to remove products from my shopping list so that I can correct mistakes.

### US-15 — View all shopping lists

As a user, I want to view all my shopping lists so that I can manage previous and current plans.

### US-16 — Delete a shopping list

As a user, I want to delete an unnecessary shopping list so that my account remains organized.

---

## Price Comparison Stories

### US-17 — Compare basket prices

As a user, I want to compare my shopping list across different stores so that I can find the cheapest option.

### US-18 — View total price by store

As a user, I want to see the total basket price in each store so that I can compare the available options.

### US-19 — Find the cheapest single store

As a user, I want the system to identify the cheapest single store so that I can buy everything in one location.

### US-20 — View an optimized multi-store basket

As a user, I want to see the cheapest store for each product so that I can minimize the total basket cost.

### US-21 — View savings

As a user, I want to see the amount I can save so that I can understand the benefit of the optimized option.

### US-22 — Handle unavailable products

As a user, I want to know when a product is unavailable in a store so that I can understand incomplete comparison results.

### US-23 — View comparison history

As a user, I want to view previous comparison results so that I can review past shopping decisions.

---

## Administrator Stories

### US-24 — Manage categories

As an administrator, I want to create, edit, and delete product categories so that the catalog remains organized.

### US-25 — Manage products

As an administrator, I want to create, edit, and delete products so that the catalog remains accurate.

### US-26 — Manage stores

As an administrator, I want to create, edit, and delete stores so that the system includes relevant locations.

### US-27 — Manage prices

As an administrator, I want to add and update product prices so that comparisons use current data.

### US-28 — Manage sale prices

As an administrator, I want to define sale prices and their validity dates so that temporary discounts are calculated correctly.

### US-29 — Import prices from CSV

As an administrator, I want to import multiple prices from a CSV file so that I can update the database efficiently.

### US-30 — View import results

As an administrator, I want to see which CSV rows were imported successfully or failed so that I can correct invalid data.

## Definition of Done

This task is complete when:

* all three user roles are represented;
* the main user flow is covered;
* the administrator flow is covered;
* each story follows the format “As a…, I want…, so that…”;
* stories are classified by priority;
* the document is stored in the repository.
