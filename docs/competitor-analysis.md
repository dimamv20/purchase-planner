# Competitor Analysis

## 1. Introduction

Before developing the Purchase Planner application, several existing shopping and grocery applications were analyzed. The purpose of this analysis is to identify their strengths, weaknesses, and opportunities for improvement.

---

# 2. Competitor Overview

## Flipp

Flipp is a mobile application that allows users to browse weekly flyers, search for products, and compare prices from different retailers.

### Advantages

- Weekly flyers
- Product search
- Price comparison
- Large number of supported stores

### Disadvantages

- No optimized shopping basket
- No shopping route optimization
- Limited shopping list management

---

## Walmart Grocery

Walmart Grocery allows users to purchase products directly from Walmart stores.

### Advantages

- Online ordering
- Shopping lists
- Real-time product availability

### Disadvantages

- Only Walmart stores
- No comparison with competitors
- No savings analysis

---

## Instacart

Instacart is an online grocery delivery platform supporting multiple retailers.

### Advantages

- Grocery delivery
- Shopping lists
- Multiple stores

### Disadvantages

- Focused on delivery
- No optimized basket calculation
- No comparison algorithm

---

## AnyList

AnyList is an application for creating shopping lists.

### Advantages

- Easy shopping list management
- Family sharing
- Recipe integration

### Disadvantages

- No price comparison
- No store comparison
- No savings calculation

# 4. Advantages of Purchase Planner

Compared to existing applications, Purchase Planner provides several unique features:

- compares prices across multiple stores;
- calculates the cheapest shopping option;
- generates an optimized shopping basket;
- estimates potential savings;
- combines shopping list management with price comparison in a single application.

These features make the application more useful for users who want to reduce grocery expenses and make informed purchasing decisions.

---

# 5. Conclusion

The analysis shows that existing applications usually focus on either shopping lists, grocery delivery, or store-specific purchases. None of the analyzed solutions combines shopping list management, multi-store price comparison, optimized basket generation, and savings calculation in a single application.

Purchase Planner aims to fill this gap by providing an integrated solution for grocery shopping optimization.
